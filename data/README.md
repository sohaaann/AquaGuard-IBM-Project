# Data

- `demo-water-quality.csv` - **SYNTHETIC** demonstration data: 120 fictional records for four fictional sites (Site A-D), 2026-08-01 to 2026-10-10, IDs `DEMO-001..120`. Generated by `scripts/build_data.py` with a fixed random seed. Not field measurements; must not be presented as research findings. It includes ordinary values, ~21% missing conductivity and ~56% missing dissolved oxygen (measured only at two sites), a few missing pH values, four records with only pH and temperature (insufficient data), values outside configured ranges, and five deliberately unusual observations.
- The same rows are embedded in `js/data.js` so the app works from `file://`; a unit test checks the two are identical.
- A CSV template with two fictional example rows is available in the app (CSV import / export -> Download CSV template).
