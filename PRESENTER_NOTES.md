## Slide 1: AquaGuard AI

Welcome. AquaGuard AI is a standalone, browser-based water-quality analysis and preliminary screening application, built for an IBM academic evaluation and aligned to UN SDG 6. It opens by double-clicking index.html: no installation, no server. State up front that it never certifies water as safe and that the demo data is synthetic.

**Likely question:** What is it in one sentence?

**Suggested answer:** A double-click web app that validates water-quality readings, flags the ones outside a documented reference range, explains why, and exports a report, without ever claiming water is safe.

## Slide 10: System architecture

Everything runs in the browser. Plain scripts, not ES modules, so file:// works. The reference configuration lives in JSON and is embedded into data.js at build time by a small dev-only script, so the app can read it without a server.

## Slide 11: Technology stack and rationale

## Slide 20: Analytics and outlier detection

Charts update with the filters. Outlier detection uses a robust z-score from the median and MAD; the demo data yields 5 unusual samples at the default threshold. It is deliberately called a statistical outlier detector, not AI or machine learning, and an unusual value is not necessarily contaminated.

**Suggested answer:** No labelled data exists and a transparent statistic is easier to explain and audit. No accuracy is claimed.

## Extra evaluator questions

**Does it say whether water is safe?** No, by design. It reports configured-range screening only and states that pH, turbidity and TDS cannot establish safety.

**Where does the data come from?** The demo data is synthetic. Users bring their own measurements; nothing is uploaded anywhere.

**Why a single HTML file instead of Python/Streamlit?** The first version needed Python and package installation; this one opens by double-click and is easier to review and share.

**What did you not verify?** Safari/Firefox, the live print dialog, thresholds against live sources, real-world value. See TESTING.md.

**Is the outlier detector AI?** No. It is a robust z-score (median and MAD). We do not claim machine learning or accuracy.

**What happens to my data?** It stays in your browser's localStorage. Reset Demo restores only the synthetic records; no files on your computer are touched.
